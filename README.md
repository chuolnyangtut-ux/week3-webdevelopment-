Personal Budget Tracker - Visual Identity & Styling
​This project fulfills the Week 3 Web Development Assignment: Design the Visual Identity of Your Budget Tracker.
​It enhances the visual design of a Budget Tracker application by establishing a cohesive color scheme, importing custom typography, styling forms and tables, and applying the CSS Box Model to create card-like visual containers.
​🎨 Design Principles & Rubric Compliance
​1. Intentional Color Palette (25%)
​Primary Accent (#0f766e - Deep Teal): Applied to table header backgrounds, primary action buttons, and active input focus rings.
​Background (#f1f5f9 - Soft Slate): A neutral gray-blue background that allows card containers to pop.
​Card Background (#ffffff): Pure white container backgrounds for clean contrast.
​Alternating Rows (#f8fafc): Subtle zebra-striping on the expense table for enhanced scannability.
​2. Custom Typography (20%)
​Headings Font: Poppins (Google Fonts, weights 600 & 700) - Delivers bold structure and clear visual hierarchy for section headers.
​Body & Inputs Font: Inter (Google Fonts, weights 400 & 500) - Ensures high legibility across table rows and form labels.
​3. Table and Form Styling (30%)
​Form Elements: Inputs and dropdowns feature consistent padding (0.65rem), rounded borders (8px), and interactive focus states (box-shadow).
​Buttons: Styled with distinct primary (teal) and secondary (light slate) color variants, hover states, and click feedback.
​Expense Table: Styled headers, cell padding (0.85rem 1rem), alternating row background colors (tbody tr:nth-child(even)), and clean row borders.
​4. CSS Box Model Strategy (25%)
​The layout is organized into three distinct visual cards:
​Header Card (.header-card): Title and introductory text.
​Form Card (.form-card): "Add New Expense" form input controls.
​Table Card (.table-card): "Recent Expenses" data table.
​Box Model Application:
​margin-bottom: 2rem separates distinct card sections.
​padding: 1.75rem provides generous inner breathing room.
​border-radius: 12px, subtle borders, and box-shadow create elevated visual cards.

​index.html — HTML structure with embedded Google Fonts links.
